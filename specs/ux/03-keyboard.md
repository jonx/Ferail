# Keyboard Map

Feraille prefers macOS conventions for platform actions and keeps Windows
Explorer/Ferail conventions where they are faster and familiar.

## Current Bindings

| Action | Binding |
|---|---|
| Edit path | `Cmd+L` / `Ctrl+L` |
| Filter current folder | `Cmd+F` / `Ctrl+F` |
| Toggle preview pane | `Cmd+P` / `Ctrl+P` |
| Get Info | `Cmd+I` / `Ctrl+I` |
| Show hidden files | `Cmd+Shift+.` / `Ctrl+H` |
| New folder | `Cmd+Shift+N` / `Ctrl+Shift+N` |
| Copy path | `Cmd+Shift+C` / `Ctrl+Shift+C` |
| Reveal in Finder | `Cmd+R` / `Ctrl+R` |
| Rename | `F2` |
| Refresh | `F5` |
| Delete to Trash | `Delete` |
| Open selected | `Enter` |
| Parent folder | `Backspace` |
| Quit | `Esc` when no modal/edit mode is active |

## List Navigation

| Action | Binding |
|---|---|
| Move cursor | Up / Down |
| Page cursor | Page Up / Page Down |
| First / last row | Home / End |
| Open | Enter |
| Parent | Backspace |

## Modal/Text Rules

- Text dialogs receive all text input while open.
- Search receives all text input while open and updates the filter live.
- Breadcrumb edit mode receives text input while active.
- Esc closes the active modal/edit/search layer before it can quit the app.
